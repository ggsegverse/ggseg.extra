# Path to bundled SUIT flatmap surface

Returns the path to the SUIT flatmap surface file
(`tpl-SUIT_flat.surf.gii`) shipped with ggseg.extra. This is the
standard 2D representation of the cerebellar cortex from the Diedrichsen
Lab SUIT template.

## Usage

``` r
suit_flatmap_path()
```

## Value

File path to the SUIT flatmap `.surf.gii` file.

## Examples

``` r
suit_flatmap_path()
#> [1] "/home/runner/work/_temp/Library/ggseg.extra/extdata/suit/tpl-SUIT_flat.surf.gii"
```
